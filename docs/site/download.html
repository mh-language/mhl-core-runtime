01 / DESKTOP

mhl studio

Design workflows as a diagram kept in sync with the code, run them live, and test the folder as an MCP server. The runtime comes bundled — nothing else to install.

Download mhl studio↓

Installers for macOS, Windows and Linux on the GitHub studio-v releases.

    The first release of mhl studio is on its way. Meanwhile, build it from source (Go, Node 22 and Rust) or install the CLI below.

    git clone https://github.com/mh-language/mhl-core-runtime
cd mhl-core-runtime/src/mhl-studio
npm install
npm run tauri build   # an installer for this machine
    First launch: the installers are not code-signed yet
    macOS
    Drag mhl studio to Applications. If it says the app “is damaged” or “can't be opened”, run once: xattr -dr com.apple.quarantine "/Applications/mhl studio.app" (or right-click the app → Open).
    Windows
    SmartScreen shows “Windows protected your PC”: click More info → Run anyway.
    Linux
    Make the AppImage executable: chmod +x mhl.studio_*.AppImage. The .deb and .rpm install through your package manager.
    Read the studio guide→

    02 / TERMINAL

    The mhl CLI

    Runs, lints, tests and serves workflows (MCP and A2A). One command installs it — and the VS Code extension too, if VS Code is installed.

    1Install

    macOS / Linux
    curl -fsSL https://raw.githubusercontent.com/mh-language/mhl-core-runtime/main/install.sh | sh
    Windows / PowerShell
    irm https://raw.githubusercontent.com/mh-language/mhl-core-runtime/main/install.ps1 | iex

    There is no published CLI binary for Intel Macs. Use mhl studio (it bundles the runtime) or build it: cd src/mhl-runtime && make build.

    Rather download the archive? Latest release page ↗ checksums.txt

    2Check it

    mhl version

    Open a new terminal first: the installer puts mhl in ~/.mhl/bin (%LOCALAPPDATA%\mhl\bin on Windows) and on your PATH.

    03 / EDITOR

    VS Code extension

    Syntax highlighting, diagnostics, completion, hover and signature help for .mh files, powered by mhl lsp. It needs the mhl CLI on your PATH.

    Open in the Marketplace↗ Open VSX (VSCodium, Cursor…)↗

    Or install from the terminal:

    code --install-extension mhl-language.mhl-language

    Offline? Download the .vsix and use Extensions → ⋯ → Install from VSIX…
