01 · GET STARTED

Your first pipeline

An MHL program combines configuration declarations with executable steps. Save the file as main.mh and run it with the CLI.

Install the runtimemacOS / Linuxcurl -fsSL https://raw.githubusercontent.com/mh-language/mhl-core-runtime/main/install.sh | sh
agent Local {
    command: "echo"
    args: ["resposta local"]
}

pipeline Hello {
    input name: string

    step Greet {
        var message = "Olá, ${name}!"
        log(message)
        var answer = Local.run(prompt: message)
        log(answer)
    }
}
runmhl run main.mh --input name="Ana"

02 · FUNDAMENTALS

Syntax without the noise

The grammar is small, readable, and block-oriented. Comments use //; objects and config accept fields separated by commas or line breaks.

✦

Declarations

agent, prompt, skill, memory, tool, mcp_server, and pipeline.

{}

Values

null, booleans, numbers, strings, arrays, objects, and closures.

↗

Composition

Use import for namespaces and use for selective imports with an alias.

Strings and durations

prompt Review(file: string) {
    """
    Revise o arquivo ${file}.
    Retorne problemas objetivos.
    """
}

pipeline Deploy {
    checkpoint: { ttl: 7d }
}

Module declarations

import "./agents.mh" as agents
use { ReviewPrompt as Review }
    from "./prompts.mh"

export agent Local { command: "echo" }

04 · LANGUAGE

Statements inside a step

Besides expressions, the body of a step or a tool method accepts imperative statements: conditionals, loops, assignment, return/break, and try/catch/finally.

StatementExampleUse
If/elseif (cond) { ... } else { ... }conditional block (not an expression)
Whilewhile (cond) { ... }conditional loop
For..infor (var item in items) { ... }iterates an array
Breakbreak "motivo"stops the loop, with an optional reason
Returnreturn valorexits the step or method
Try/catchtry { } catch (err) { } finally { }captures the error as a string
tool Counter {
    count(items) -> {
        var n = 0
        while (n < items.size()) { n = n + 1 }
        return n
    }
}

pipeline Sync {
    step Check {
        for (var file in changed_files) {
            if (file.size > max_size) break "arquivo grande demais"
        }

        try {
            var config = fs.read("config.json")
        } catch (err) {
            log.warn("config ausente:", err)
        } finally {
            log.info("verificação concluída")
        }
    }
}
NOTE

catch (err) binds err to the error's message (a string); finally always runs, even when the try or catch propagates a return, break, or goto.

05 · AI

Agents, without coupling

The same abstraction can call a local CLI process or an Ollama model. Configuration stays separate from the flow.

agent LocalModel {
    engine: "ollama/qwen2.5-coder"
    endpoint: "http://localhost:11434"
    temperature: 0.2
    retry: {
        max_attempts: 3
        delay: 2s
        retry_on: ["timeout", 503]
    }
}

The call is always an expression:

var answer = LocalModel.run(
    prompt: Review(file: "main.go", code: source),
    schema: schema_text
)

06 · CONTEXT

Prompts as reusable code

${code}

Wrap I/O in tools and pick the memory type based on how long the data lives and its shape.

08 · ORCHESTRATION

Flows that keep going

Steps run in order, can redirect with goto, and persist progress with per-step checkpoints.

pipeline Recoverable {
    checkpoint: {
        enabled: true
        strategy: "per_step"
        storage: "file"
        ttl: 7d
    }

    step Verify {
        var result = project.test()
        if (result.exit_code != 0) goto Repair
    }

    step Repair {
        log.warn("corrigir e tentar novamente")
    }
}
input→step→checkpoint→resume
NOTE

State lives in .mhl/state/. A completed run clears the checkpoint; a failure lets you mhl run file.mh --resume.

Prefixing with loop repeats the whole pipeline according to a repeat policy:

memory poll {
    type: "kv"
    store: "memory"
}

loop pipeline Poll {
    repeat: {
        stop_when: poll.get("status") == "done"
        max_iterations: 20
    }

    step Check {
        var status = if (project.test().exit_code == 0) "done" else "pending"
        poll.set("status", status)
    }
}
NOTE

stop_when runs in its own environment, outside any step — a step's var isn't visible there, so state observed across iterations has to go through memory. max_iterations is a hard ceiling; both fields are optional.

09 · INTEGRATIONS

MCP and resilience

    url: "https://example.test/mcp"
    headers: {
        "Authorization": "Bearer " + env("MCP_TOKEN")
    }
}

Zero-trust by default

Don't commit tokens. Use env("API_TOKEN"), prefer argv over concatenated commands, and review logs/trace before enabling in production.
