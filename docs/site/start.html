Your first workflow

Create a .mh file, check the code, and see the result in your terminal.

From file to terminal

You only need the MHL CLI. Save the file in a folder and run the commands from that folder in your terminal.

1Install MHL

macOS / Linux
curl -fsSL https://raw.githubusercontent.com/mh-language/mhl-core-runtime/main/install.sh | sh
Windows / PowerShell
irm https://raw.githubusercontent.com/mh-language/mhl-core-runtime/main/install.ps1 | iex
Manual installation and CLI verification →

2Save as hello.mh

workflow Hello {
    step Greet {
        log("Hello, Ana!")
    }
}

3Check and run

mhl lint hello.mh
mhl run hello.mh

↳ Hello, Ana!
