MHL · STANDARD LIBRARY · METHOD REFERENCE

Every callable, with its types.

This page lists each method and built-in function you can call from an MHL program — the parameters it takes, the types it expects, and what it returns. For the language itself (declarations, syntax, control flow), see the Language Reference.

SIGNATURE NOTATION

NotationMeansExample
string number bool null anyThe primitive value types. any is "no constraint".fs.read(path: string)
T[]An array whose elements are T.string[], any[]
{ field: T, ... }An object with those named fields.{stdout: string, exit_code: number}
{ string: T }An object used as a string-keyed map.headers: {string: string}
durationA duration literal.30s, 2m, 7d
(p: T) -> RA lambda taking p and returning R.filter((f) -> f.ok)
name:A named argument — written with its label at the call site.agent.run(prompt: "…")
param?Optional — may be omitted.get(key, default?)
...paramVariadic — zero or more of that argument.log(...values)

A "raises" outcome unwinds like any evaluation error: it aborts the step/run unless a try { … } catch (e) { … } around the call catches it. A non-zero process exit_code is not a raise — it is a field on the returned value for you to inspect.

01Global functions

Executable

Available in any expression position — a step body, a describe block, a tool method, a condition.

SignatureParametersReturnsNotes
log(...values: any) -> null values — any number of values of any type null Formats each value (strings raw, numbers trimmed, objects as JSON) and writes one space-joined line to stdout.
fail(...values: any) -> never values — same formatting as log raises Raises an error whose message is the joined values. An uncaught fail makes mhl run exit non-zero. Catchable with try/catch.
env(name: string) -> string name — the environment variable name string Reads an OS environment variable. Returns "" when unset (no separate null). Exactly one argument.

02Collection methods

Executable

03agent

Executable

A declared agent exposes one method. Its declaration (engine, retry, cache, fallback, before/after, …) is covered in the Language Reference.

SignatureParametersReturnsNotes
<Agent>.run(prompt:, schema:?) -> string prompt: required — a string literal (${…}-interpolated) or a reference to a declared prompt template with its arguments, e.g. prompt: AuditPrompt(service: "auth"). Must be non-empty. schema: optional — any expression that evaluates to a string (commonly json.stringify({...})); passed to the model as the requested output shape. string The model's response text. Honors the agent's retry/fallback and runs its before/after hooks. Raises if every attempt (and every fallback) fails.

04prompt

Executable

A declared prompt is called like a function to render it to a string.

SignatureParametersReturnsNotes
<Prompt>(name: value, …) -> string Named arguments, one per declared parameter — value is any expression (variable, field access, another prompt call, literal). string Renders the template with parameters interpolated. Use anywhere a string is expected, most often agent.run(prompt: …). from: [A, B] composition is declaration-level, not a call — see the Language Reference.

SignatureParametersReturnsNotes

07a2a_agent

Executable

A declared a2a_agent exposes four methods for talking to a remote agent over the A2A protocol (revision 0.2.x, JSON-RPC 2.0 over HTTP). Each is stateless; an unresolved env(...) credential aborts the call. Configuration (url, headers, poll_interval, poll_timeout) is in the Language Reference.

SignatureParametersReturnsNotes
<Agent>.send(message: string, context?: string) -> object message — the user message; positional or named message:. Sent as one text part. context — a prior context_id for a follow-up turn; positional (2nd) or named context:. object Issues message/send, then polls tasks/get every poll_interval to a terminal state (or poll_timeout). Returns a normalized {kind, text, ...} — a message or a task. A task stuck in input-required/auth-required raises.

08Native operations

Executable

The fixed namespaces any expression (or a tool method body) can call: cmd, fs, git, http, json, log, time. They accept a mix of positional and named arguments. Unless noted, a failure to perform the operation raises; a completed process with a non-zero exit is returned, not raised.

cmd

Subprocess execution. Prefer the argv-array form — it passes each argument verbatim with no shell parsing.

SignatureParametersReturnsNotes
cmd.exec(command: string | string[], timeout?: duration) -> {stdout: string, stderr: string, exit_code: number} command — a command string (run via shell) or an argv arraytimeout: — max run time; cancels the process group on expiry {stdout, stderr, exit_code} Non-zero exit_code is a value to inspect, not a raise.
cmd.exec_all(commands: (string | string[])[], timeout?: duration) -> {stdout, stderr, exit_code}[] commands: — array of commands, each a string or an argv array; positional or namedtimeout: — applies per command array of results One result object per command, in order.

http

One op per verb — get, post, put, patch, delete, head, options — all sharing the parameter surface below. url is a named url: or the first positional; every other argument is named and optional. A transport failure (DNS, refused connection, timeout, a bad client certificate) raises; a non-2xx response is returned in status unless raise_for_status: true.

ParameterTypeEffect
headers:{string: string}Request headers. An explicit Authorization here wins over auth:.
query:{string: string}URL-encoded and merged into the URL's existing query string.
body:anyJSON-encoded; sets Content-Type: application/json.
text:stringRaw request body, sent as-is. No Content-Type is forced.
form:{string: string}application/x-www-form-urlencoded body. body/text/form are mutually exclusive.
timeout:durationOverrides the 30s default.
follow_redirects:boolDefault true. false returns the 3xx response itself.
raise_for_status:boolDefault false. true turns a non-2xx response into a raised error.
auth:{bearer: string} or {basic: {user, password}}Sets the Authorization header (Bearer … or Basic base64).
tls:{cert, key, ca: string, insecure: bool}cert/key — PEM client-certificate + key paths for mTLS. ca — extra PEM CA bundle added to the system pool. insecure: true — skip server-cert verification (development only).
proxy:stringExplicit proxy URL (http://, https://, socks5://) for this call. When unset, the standard HTTP_PROXY / HTTPS_PROXY / NO_PROXY environment variables are honoured.

A bearer token, basic-auth password, or Authorization/Cookie header value passed to any http.* call — and any env("…_TOKEN"/"…_SECRET"/"…_API_KEY") read — is registered as a secret and masked as [REDACTED] in logs, error output, and persisted checkpoints.

SignatureReturnsNotes
http.<verb>(url: string, …) -> {status: number, body: string, headers: {string: string}, ok: bool, json: any} {status, body, headers, ok, json} ok is status in 200–299. json is the parsed body when the response Content-Type is JSON, otherwise null. headers joins multi-valued headers with ", ".
http.download(url: string, path: string, …) -> {status: number, path: string, bytes: number, ok: bool, headers: {string: string}} {status, path, bytes, ok, headers} Streams a GET response straight to path (atomic write, parent directories created) instead of returning the body — for large or binary artifacts. On a non-2xx response no file is written and ok is false, unless raise_for_status is set. Accepts headers/query/timeout/auth/tls/proxy.
