# concatenation

String concatenation with `+` and with `${...}` interpolation.

- [concatenation.mh](concatenation.mh) — joining strings with `+`, and interpolating a
  variable inside `${...}`
- [string_plus_scalar.mh](string_plus_scalar.mh) — `+` joins a string with a number,
  bool or enum value (`"n=" + 3`); a string with null/object/array is still an error
