# math_operations

Arithmetic on mhl's single `number` type, over both integral and fractional values.

- [float_sum_operations.mh](float_sum_operations.mh) — `+` on decimals
- [float_subtraction_operations.mh](float_subtraction_operations.mh) — `-` on decimals
- [float_multiplication_operations.mh](float_multiplication_operations.mh) — `*` on decimals
- [float_division_operations.mh](float_division_operations.mh) — `/` on decimals
- [integer_sum_operations.mh](integer_sum_operations.mh) — `+` on whole numbers
- [integer_subtraction_operations.mh](integer_subtraction_operations.mh) — `-` on whole
  numbers
- [integer_multiplication_operations.mh](integer_multiplication_operations.mh) — `*` on whole
  numbers
- [integer_division_operations.mh](integer_division_operations.mh) — `/` on whole numbers
- [module_integer_operations.mh](module_integer_operations.mh) — `%` (modulo)
