# conditional_statements

`if`/`else` as both an expression (returns a value) and a classical block statement.

- [conditional_expression.mh](conditional_expression.mh) — `if (cond) a else b` used as a
  value-producing expression
- [if_statement.mh](if_statement.mh) — the same expression form, true branch
- [if_else_statement.mh](if_else_statement.mh) — the same expression form, false branch
- [if_else_if_statement.mh](if_else_if_statement.mh) — chained `if / else if / else`
  expression
- [classical_if_statement.mh](classical_if_statement.mh) — `if (cond) { ... } else { ... }`
  as a block statement that mutates a variable instead of returning a value
